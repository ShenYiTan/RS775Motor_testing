# RS775Motor_testing

Arduino-based testing platform for the **RS775 brushed DC motor** using a **775-P16 Hall encoder** and **MD10C motor driver** for flywheel-based launching mechanism. The documentation also explore general types of motor and discuss the specification and rating when choosing motor for specific application.  

## Features
- Closed-loop PI speed control
- Quadrature encoder (4× decoding)
- Real-time RPM measurement
- Teleplot visualization support
- Adjustable target RPM via Serial Monitor

## Hardware
- Arduino Uno
- RS775 DC Motor
- 775-P16 Hall Encoder
- Cytron MD10C Motor Driver
- 12V Power Supply / 3S LiPo
